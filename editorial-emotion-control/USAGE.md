# Portrait Emotion Direction

Category: **VisualOS**

## Purpose

Control subtle expressions, posture and lighting in portrait prompts.

## Invocation

Installed skill name: `editorial-emotion-control`.

```text
$editorial-emotion-control Write a portrait prompt expressing restrained sadness without theatrical acting.
```
