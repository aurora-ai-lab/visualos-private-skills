# Batch Visual Prompts

Category: **VisualOS**

## Purpose

Plan distinct visual directions and produce consistent, independent prompts for a series.

## Invocation

Installed skill name: `prompt-batch-conductor`.

```text
$prompt-batch-conductor Write six coordinated image prompts with different compositions.
```

## Files

- [Skill instructions](SKILL.md)
- Repository folder: `prompt-batch-conductor`

The invocation name comes from the skill frontmatter, not the folder label. Image generation requires an available image-generation tool; prompt-only requests do not imply generation.
