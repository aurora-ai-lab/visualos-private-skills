# 南鸢写真提示词

南鸢写真与人像摄影 Skill。支持完整中文 Prompt、系列母版、同系列变体、网页端抽卡关键词、参考图拆解，以及“换一位人物、按同一摄影企划重新拍摄新分镜”的摄影方案复拍模式。

## 安装

```bash
npx skills add nuyoah-ai-works/nuyoah-xiezhen-prompt -g -y
```

更新已有安装：

```bash
npx skills update nuyoah-xiezhen-prompt -g -y
```

更新后新建任务或重新加载 Agent，让新版指令进入上下文。

## 它解决什么

普通请求默认只交付 Prompt。只有用户明确要求生图时，摄影方案复拍模式才会在 Codex Image 中生成指定数量的图片并逐张检查。完整 Prompt、参考职责、质量状态和追溯记录直接在对话中交付；Eagle 只是检测可用后执行的可选归档，未安装或不可用不会中断任务。

摄影方案复拍会把人物身份与本张表情分开控制：身份图只提供稳定五官锚点，目标场景中的具体事件负责眉眼、呼吸、嘴角、视线和身体反应；同时按参考图重建主体清晰区、主导大形、次级细节和低细节留白，避免把“场景丰富”误写成“背景每一层都清楚”。

用户要求重做时，每一轮都会回到原始人物图与对应写真参考，从摄影方案和本轮反馈重新编译完整 Prompt。上一轮生成图只用于判断哪里失败，不作为新一轮输入；新图也直接对照原作验收，不以“比上一轮好”代替风格保真。

原作若依赖欠曝、失焦、堵黑和偶发抓拍，复拍会额外检查模型是否自行补入连续暖色轮廓光、稳定脸部焦点、皮革塑形、正面回填或英雄式构图，并把这些商业抛光改写为原作支持的曝光与焦点关系；精致 editorial 原作不会被统一做脏。

这不是换脸工具，也不承诺像素级复刻。它重建的是可观察的摄影方案：光源、机位、曝光、背景信息层级、人物事件和成像质感。结果仍受生成模型、参考图质量与人物授权影响。

## 署名与归档

- 默认不在图片中加入 `nuyoah` 或任何其他署名、水印。
- 只有用户明确要求并给出署名文字时，才把该文字写入 Prompt。
- Eagle、个人知识库和其它本地 Skill 都不是使用本 Skill 的前提；Eagle 归档成功时会额外返回 Eagle ID，失败时仍保留完整的对话交付。

## 普通提示词

```text
使用 $nuyoah-xiezhen-prompt，为这个主题写一组写真提示词。
```

## 摄影方案复拍

```text
使用 $nuyoah-xiezhen-prompt。参考这组写真，换一位原创人物，像去同一家摄影店拍同一套企划那样重新设计 5 张新分镜，并直接生图。
```

## 文件结构

- `SKILL.md`：触发、授权、输出和跨环境边界。
- `references/`：提示词模板与摄影方案复拍工作流。
- `evals/`：触发、皮肤反射和复拍回归案例。
- `tests/`：公开发行与行为合同测试。
- `CHANGELOG.md`：公开版本变化。

## 能力边界

- 只要 Prompt 时不会擅自生图。
- 明确要求生图但环境没有图片生成工具时，会交付完整 Prompt 并说明未执行生成，不伪造结果。
- Eagle、个人知识库和其他本地 Skill 都不是运行前提。
- 使用参考图和人物图前，请自行确认版权、肖像权、商标与平台规则。
