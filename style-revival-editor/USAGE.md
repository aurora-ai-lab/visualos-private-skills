# Photo Style Transformation

Category: **VisualOS**

## Purpose

Translate photos into illustration, paper, hand-drawn or retro styles while preserving key features.

## Invocation

Installed skill name: `style-revival-editor`.

```text
$style-revival-editor Write a hand-drawn transformation prompt that preserves this subject.
```
