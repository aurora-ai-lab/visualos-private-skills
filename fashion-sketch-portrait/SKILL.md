# fashion-sketch-portrait

把一张人物照片转成"高级半写实时尚手绘肖像"。只更换媒介，不重新设计人物。

## 核心原则

**身份保真优先于风格表达。** 任何笔触都不得覆盖或改写识别特征。宁可少画一笔，不可改形一分。

**通透 ≠ 褪色。** 清透来自纸白高光和留白，不来自降低饱和度。

## Workflow

1. **提取身份锚点（不可变）**：脸型、五官比例、眼型、眉形、鼻子、嘴唇、表情、视线、发型 / 发色 / 刘海、头部角度、身体朝向、手势、服装、饰品、辨识度道具。
2. **提取风格变量（可重绘）**：笔触密度、留白比例、彩色刷痕、边缘收束方式、未完成区域位置。
3. **分层分配完成度**：脸部最高 → 头发中高 → 服装中等 → 身体与下缘最低（断开留白）。
4. **配置色板**：肤色清透明亮自然 + 纸白高光 + 轻微粉色血色；唇色取珊瑚粉 / 豆沙粉 / 原照唇色，清楚但有透明感；黑发保持黑；服装保留原色相。
5. **配置背景**：85%—90% 纯白绘画纸，不绘制原照片环境。仅在头发后方、肩膀和身体两侧点缀少量天空蓝 / 湖蓝 / 薄荷绿 / 薰衣草紫 / 粉色自由彩铅或马克笔刷痕——面积小，但颜色清晰可见，不过度降饱和。
6. **处理边缘**：发尾、肩膀、服装下缘、身体边缘自然断开、留白并融入纸张，形成未完成手稿感。
7. **放置点缀**：人物旁的自然留白处加一个很小的单线条手绘爱心（蓝 / 紫 / 粉），不填色。
8. **输出提示词**：3:4 竖版，中文，可直接投喂图像模型。用户要求批量时，逐张输出互相独立的提示词。

## 必须保留

| 类别 | 内容 |
|---|---|
| 面部 | 脸型、五官比例、眼型、眉形、鼻形、唇形、嘴型、表情、视线方向 |
| 头部与身体 | 发型、发色、刘海、头部角度、身体朝向、手势 |
| 造型 | 服装款式与颜色、饰品（眼镜 / 耳环 / 发饰 / 帽子 / 围巾 / 耳机 / 首饰 / 包）、花朵等辨识道具 |

## 禁止

AI 网红脸、二次元、动漫、韩漫、3D、数字 CG、油画、厚涂、传统素描、炭笔、纯水彩、儿童蜡笔、粗黑统一描边、整体低饱和、灰蒙感、白雾滤镜、整体褪色、完整复制照片背景、复杂场景、文字、Logo、水印。

同时禁止：放大眼睛、缩小鼻子、改变脸型或嘴型、把黑发画成浅灰、把服装原色画成低饱和。

## 自检清单

- [ ] 脸型、眼型、眉形、鼻形、唇形与原照一致，未被"标准化"
- [ ] 表情与视线方向一致
- [ ] 发型、刘海走向、发色一致，黑发仍明显是黑发
- [ ] 服装色相保留（粉仍是粉、蓝仍是蓝、红绿同理）
- [ ] 高辨识度道具全部在场，颜色与造型对应原照
- [ ] 纯白背景占比 85%—90%，彩色刷痕量少但清楚可见
- [ ] 边缘存在断开与留白，非整幅收边
- [ ] 留白处有单线条手绘爱心，未填色
- [ ] 画面为 3:4 竖版，无文字 / Logo / 水印
