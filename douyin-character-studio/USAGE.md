# Douyin Character Studio

Category: **VisualOS**

## Purpose

把原创 AI 角色运营与 VibeShot 视觉知识库结合，规划适合抖音的连续短视频和低成本图片先行工作流。

## Invocation

Installed skill name: `douyin-character-studio`.

```text
$douyin-character-studio
结合我的 VibeShot 知识库，为 COOLCAT 设计 5 条抖音短视频，先给静帧方案。
```
