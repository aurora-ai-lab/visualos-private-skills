# douyin-character-studio

把一个原创 AI 角色和 VibeShot 知识库里的视觉案例结合起来，形成可连续更新、可低成本测试、可逐步接单的抖音内容系列。

## 适用范围

当用户希望：

- 用 VibeShot 知识库寻找抖音短视频创意、提示词或视觉案例。
- 为 COOLCAT 或其他原创 AI 角色规划连续短视频。
- 把图片、色卡换装、旅行转场和角色日常接成 8–20 秒的抖音系列。
- 先做低成本静帧测试，再决定是否投入图生视频成本。

不用于：

- 直接复制社区作品、创作者的人物、镜头、文案、服装组合或独特转场。
- 冒充真实人物、伪装真实偷拍或制造现实误导。
- 在未确认静帧和素材权利前批量生成昂贵长视频。

## 两个来源的分工

### AI Character Worldbuilder

负责角色是谁、为什么值得关注、连续内容如何衔接、用户如何参与，以及公开内容如何连接到肖像定制或品牌视觉服务。

### VibeShot 知识库

负责提供可检索的视觉案例、提示词结构、镜头想法、风格方向和制作方法。默认优先读取本地 VibeShot 知识库；如果本地没有同步目录，再使用用户有权限访问的 GitHub 仓库 `aurora-ai-lab/vibeshot-kb-private`，只读取当前任务需要的文章、索引和资源说明。

知识库只提供研究材料，不自动成为发布素材。每个案例都要经过原创改编和权利检查。

## 工作流

1. 固定目标平台为抖音，先确定视频时长、画幅、角色和本轮测试预算。默认采用 9:16、8–15 秒和图片先行。
2. 从 VibeShot 知识库中检索 1–3 个相关案例，记录标题、视觉机制、镜头节奏、可复用抽象结构和不可直接使用的元素。
3. 调用角色母版思路，锁定人物脸部、发型、成年状态、体型比例、气质、核心服装和品牌识别点。
4. 把知识库案例改写成原创抖音概念：改变人物、场景、服装、动作、色彩、文字和叙事关系，只保留可解释的结构，例如“色卡换装”“同一人物多场景”“首帧到旅行地图”“前后对比”。
5. 先交付低成本静帧方案：首帧、主体分镜、变化节点、结尾画面和 5–9 张素材清单。检查同一张脸、服装对应、动作连贯和色卡匹配。
6. 静帧确认后，再调用 `color-card-outfit-lab` 设计图生视频提示词；用户只要图片时停在静帧阶段。
7. 为抖音补齐发布包装：前 1 秒钩子、封面文案、标题、字幕、结尾互动和系列下一集的承接问题。
8. 发布后只根据可观察数据调整下一条：首秒停留、完播、重复观看、评论、主页访问和私信。不要因为单条播放低就随意更换角色脸和账号主题。

## 抖音内容判断标准

- 前 1–2 秒能看懂变化或悬念。
- 角色在不同视频里仍然能被认出。
- 画面机制可以在下一条重复，但事件和视觉结果有变化。
- 用户能用一句话参与评论，例如选择下一套颜色或下一座城市。
- 低成本图片版已经成立，再决定是否进入视频生成。

## 默认交付

按以下顺序输出：

1. VibeShot 相关案例摘要与可借鉴结构
2. 原创改编边界
3. COOLCAT 角色连续性约束
4. 8–15 秒分镜表和静帧清单
5. 图片提示词或图生视频提示词
6. 抖音标题、首秒字幕、结尾互动和系列下一集
7. 成本分级：图片测试、轻量图生视频、完整视频
8. 可接的服务包装，例如角色视觉企划、换装内容系列和品牌主视觉
